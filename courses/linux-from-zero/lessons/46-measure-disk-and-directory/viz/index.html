Lesson 46

The tree drawing is not the disk. df measures the tank. du weighs the papers in a folder.

The disk

df reads the tank

df -h / on this machine reports the overlay filesystem: 252G size, 17G used, 223G free.

The folder

du weighs a tree

du -sh ~/linux-workshop is 16K. That is the papers in the workshop, not the 252G tank.

Human sizes

-h speaks in K and G

GNU -h prints powers of 1024. The rent papers folder is 4.0K. Home is 3.5G.

Not the drawing

A tall barn can be empty

ls shows names. du shows how much those names use. Do not mount a new filesystem here.

Lesson 37

Copy, rename, remove. Keep the original. Destroy nothing you still need.

Copy

A second file

cp rent-log.txt sep-draft.txt. The paid-August note stays. A September draft appears next to it.

Rename

A clearer name

mv sep-draft.txt sep-due-draft.txt. Same bytes. New name. The old name is gone.

Remove

Only the extra

A mistaken oops.txt is unlinked with rm. The workshop itself is not removed. The original is not removed.

Keep

The note remains

ls -l still lists rent-log.txt beside the draft. echo is not a copy. This is.

cd ~/linux-workshop. cp the note. mv the copy. rm only oops.txt. ls -l still shows rent-log.txt.

Lesson 43

Devices live as files in /dev. Find a real node and say what kind of file it is.

Named holes

/dev is the wall

Special files live under /dev. intro(4) calls them device files. You open them by name, like a socket on the wall.

Character

/dev/null is a sink

file /dev/null says character special (1/3). null(4) is a data sink. ls -l starts with c. Do not echo the word null.

Block

/dev/vda is the disk

On this machine file /dev/vda says block special (254/0). ls -l starts with b. Do not cat the disk.

Ask file

Kind is a fact

file /dev/null /dev/vda prints both kinds. The first letter of ls -l waits for the next lesson.

ls -ld /dev. ls -l /dev/null and /dev/vda. file /dev/null /dev/vda.

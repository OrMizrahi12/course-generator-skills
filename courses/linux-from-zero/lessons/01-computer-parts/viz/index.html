A computer is made
of four parts.

Thinks

CPU

The brain. It runs every instruction.

Holds, for now

Memory

The desk. Fast. Empty when the power goes.

Keeps

Disk

The cupboard. Files stay when you leave.

Shows

Screen

The window. This is how you look in.

This computer has all four.

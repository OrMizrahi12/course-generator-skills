# Lesson 7 research brief

- **Lesson:** 7 — See what GNU is
- **After:** After the picture of the GNU project: show a real GNU program’s `--version` on this machine
- **Audience:** Zero computer background; picture-first. Act II. Still no `uname` (that names the kernel).

## Feature

GNU is a free Unix-like operating-system project announced by Richard Stallman on 27 September 1983. The name is the recursive acronym **GNU’s Not Unix**. The programs a person types on this box — `ls`, `bash`, `cat` — are GNU. The Linux kernel is not GNU. This lesson names GNU and proves a GNU program on disk.

It is **not** the kernel, not the four freedoms lecture (lesson 11), not GCC.

## Human job

A person already typed `ls` in lesson 6 and thought it was “Linux.” They need the GNU picture, then `--version` on a program they already used, because that line is how you *see* GNU sitting in userland. Required: GNU project picture, then `ls --version` printing GNU coreutils (and Stallman in the writers line).

If you skip `--version`, GNU stays a logo. If you run `uname`, you teach the kernel instead.

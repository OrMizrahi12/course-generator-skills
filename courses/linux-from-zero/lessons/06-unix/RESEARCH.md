- **Lesson:** 6 — See what Unix is
- **After:** After the family-tree picture: this Linux box still speaks Unix ideas (users, files as a tree). Unix is the grandparent, not the stickers on this screen
- **Audience:** Zero computer background; picture-first. Act II starts here. Still no `uname`.

## Feature

Unix is a 1969 Bell Labs operating system (Ken Thompson, Dennis Ritchie). Linux cloned Unix *ideas* — a rooted tree of files, named users — it is not a sticker of AT&T Unix on this disk. Mac is a Unix-certified cousin (later). Windows is not Unix.

It is **not** GNU, the Linux kernel, distro names, or POSIX certification on this box.

## Human job

A person who just learned “Linux is one household OS” still thinks Linux appeared from nowhere. They need the grandparent picture, then proof that **this** machine still speaks those two Unix ideas. Required: family-tree picture, then `ls /` (rooted tree) and `ls /home` (users as directories).

If you skip the live tree, Unix stays a history poster. If you boot nothing Unix-branded, do not fake it.

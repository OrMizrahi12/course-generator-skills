# Lesson 4 research brief

- **Lesson:** 4 — See the four jobs an OS does
- **After:** Match files, programs, users, and devices on this desktop to the picture
- **Audience:** Zero computer background; picture-first

## Feature

An OS does four jobs that IBM names as core functions: **file system management**, **process management** (programs), **security and access** (users), and **device management**. This lesson names those four and matches each to something already on this machine.

It is **not** chmod, useradd, or writing a driver. Those come later.

## Human job

A person now knows there is a middle layer. They need four named jobs, because “the OS manages things” is still fog. Required: picture of the four jobs, then on this machine `ls` a real directory (files), `ps` (programs), `whoami` (users), `ls /dev` (devices). Without the four matches, the poster does not prove the jobs.

## Done on screen

1. HyperFrames: four labeled photographs — files, programs, users, devices.
2. Terminal 19pt: `ls /home/ubuntu`, `ps -o pid,cmd`, `whoami`, `ls /dev`. Last frames hold the device list (or the last finished command) after all four ran.

## Sources used

- IBM, *What is an operating system?* — file system, process, security/access, device management
- This host: `/home/ubuntu`, `ps`, `whoami` = ubuntu, `/dev`

The four commands typed, full output. Do not paste listings.
